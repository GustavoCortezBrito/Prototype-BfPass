## 🎓 Glossário

### Termos Técnicos

- **Expo**: Framework para React Native
- **AsyncStorage**: Armazenamento local
- **Context API**: Gerenciamento de estado
- **Stack Navigator**: Navegação em pilha
- **Mock**: Dados simulados
- **TypeScript**: JavaScript tipado
- **Component**: Componente reutilizável
- **Screen**: Tela do aplicativo
- **Hook**: Função React especial

### Termos do Projeto

- **BF Pass**: Nome do aplicativo
- **Cupom**: Desconto oferecido
- **Resgate**: Ação de usar um cupom
- **Admin**: Administrador do sistema
- **User**: Usuário comum
- **Role**: Permissão do usuário
- **Dashboard**: Tela inicial
- **Parceiro**: Empresa que oferece cupom

## 📞 Suporte

### Problemas Comuns

1. **App não inicia**
   → Consulte COMANDOS.md (Troubleshooting)

2. **Erro de dependências**
   → Execute `npm install` e `npm start -- --clear`

3. **Não consigo fazer login**
   → Verifique as contas de teste em GUIA_RAPIDO.md

4. **Como adicionar funcionalidade?**
   → Consulte CUSTOMIZACAO.md

5. **Como testar?**
   → Consulte TESTES.md
