# 🎉 BF Pass - Protótipo Completo

## 📱 Aplicativo de Cupons e Benefícios

Protótipo completo em React Native/Expo inspirado no TotalPass, com sistema de autenticação, cupons e painel administrativo.

---

## 🚀 Início Rápido

```bash
cd BF-Pass
npm start
```

Escaneie o QR Code com o Expo Go app.
